This is the first post on the site. It exists mostly to prove the pipeline
works: Markdown in, a page out, an RSS entry, and a Turkish translation living
next to it under the same slug.

## What goes here

Notes on things I build, problems that took longer than they should have, and
tools worth recommending. Posts are written in MDX and live in the repository,
so every change to a post is a commit.

```ts
const greet = (name: string): string => `Hello, ${name}`;
console.log(greet('world'));
```

If a post has no translation in the other language, the language switcher takes
you to that language's blog index instead of a dead link.

## Finding things

Every heading gets an id and a `#` anchor, so any section of a post has its own
link. Longer posts show a table of contents above the body, and the search page
covers every post in both languages.
